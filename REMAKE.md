# Remake mode: frame-locked 1:1 copy of a reference video for another brand (scripts/remake/)

Use when asked to "remake / recreate this launch video for my brand" (the split-screen "original | copy" format). Ask before downloading the reference video.

- **Phase 0, analysis (no building):** download REF → `remake_analyze.py` extracts all frames (0-based) to `ref/full`, the audio to `ref/audio.wav`, detects hard cuts (mean-abs-diff spikes) and writes 6-frame contact sheets. Read the sheets, write `SPEC.md`: shot table (id, f0–f1, REF content, brand swap) and swap rules. Most "cuts" in modern launch films are continuous camera/morph moves: expect only ~10–15 hard cuts, and SPEC boundaries a few frames off (the build agents fix them).
- **Phase 1, engine (you, before agents):** copy `core.js` + `index.html` (pure `seek(F)`, SHOT registry, camera, cursor, words, pixelDissolve, palette filter that re-hues leftover old-brand colour) and `remake_stub.py` (one placeholder file per group). Serve, smoke-test with `remake_render.py compare out/test 10 600 1200`.
- **Phase 2, parallel build:** split the shots into ~4 contiguous groups, one agent each (fill `BRIEF_TEMPLATE.md`); each writes ONLY `shots/Gx.js` and verifies with side-by-side compare sheets. A 5th agent does audio: analyse REF (BPM, drop, hard stop, SFX hits, voice slots from STT timings only), a royalty-free track stretched ≤ 8 % and cut on bars so drops land on REF times (or a synthesised score, AUDIO.md), SFX on REF hits, −14 LUFS. **Never reuse REF music or voice.**
- **Phase 3, integrate:** full render in parallel chunks (`remake_render.py full out/full a b`), `remake_sync.py encode` (muxes `out/mix.wav`), `split` (two panels with a gap, labels "original" / "copy", `setsar=1` or X distorts it), `stacked` (QA). `remake_qa.py`: REF|ours one frame per second + group seams + old-brand colour scan. Fix, re-render, deliver.
- **Honesty:** no fake "made in 15 minutes"; credit/tag the original brand in the post; no co-marks implying a partnership; no REF people photos.
- Helpers agents tend to re-invent (add to core when you need them): text placed by ink edge + fitFont, hex colour mix, REF-shaped cursor, per-frame keyframe tables.
